# BOUNCE Inc — Premium Immersive Website Redesign

Concept redesign of [bounceinc.com.au](https://bounceinc.com.au) as a premium, cinematic, conversion-focused experience. By WeBuild Creative Studio.

**Direction: "Suspended"** — Australia's home of freestyle movement. Ink-black canvas, electric-lime signature, action-pink CTAs, motion that feels weightless.

## Contents
- **`index.html`** — working, self-contained reference homepage (Direction A). No build step. Open in any browser.
- **`STRATEGY.md`** — full 8-phase master plan: audit, strategy, 3 creative directions, experience design, motion/3D plan, Higgsfield prompts, tech build, review.

## Run
```bash
open index.html    # or: python3 -m http.server
```

## Highlights
- Venue finder promoted to a hero feature — instant search + state filters over all 26 venues.
- Fully accessible: skip link, keyboard nav, `prefers-reduced-motion`, `aria-live` results, semantic landmarks.
- Zero dependencies (fonts via CDN). Clean upgrade path to Next.js + GSAP/Fable + Three.js for production.

Reference homepage + strategy complete. Full multi-page production, cinematic assets, and CMS wiring are delegated squad workstreams (see `STRATEGY.md § Production Plan`).
